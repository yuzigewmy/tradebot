# 永续回测与实时模拟

本次使用 OKX BTC-USDT-SWAP 和 ETH-USDT-SWAP，从北京时间 2026-08-18 08:00 到 2026-11-18 08:00（结束时间不含新开仓）。起点前的历史仅作指标预热。`perpetual-entry/v1` 的两套策略和 Skill 冻结，完整策略指纹出现在 `summary.json`。

## 复跑

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m spot_agent.perpetual_backtest --start 2026-08-18T08:00:00+08:00 --end 2026-11-18T08:00:00+08:00 --cache data/okx-history --out artifacts/perpetual-backtest-2026-11-18 --stage report
```

原机 `--stage report` 使用当次下载的行情和当次真实模型结果出账，不重复支付模型调用费用。另行下载和研判时使用 `--stage data`、`--stage review`，或省略 `--stage` 一次执行。用 `--review-cache` 可以明确选择过往研判目录。盘口按合约和日期从官方压缩流读取，只缓存候选分钟的有效报价；首次仍需较多网络流量。真实研判需要本地 `.env` 中的网关配置。`data/` 和 `artifacts/` 均由 Git 忽略。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m spot_agent.perpetual_paper_live
```

实时命令开启一个新的模拟账户，后台按秒处理已收盘的公共成交及标记价。每次会话生成独立的信号和成交账本，重启即创建新会话。账本记录会话结束时仍在持有的仓位。现有网页继续提供行情分析及信号展示。模拟账户无私有 API 和下单入口。

## 共用执行规则

- 一笔 100 USDT 本金；两品种可并行，各最多一仓，不加仓或自动反手。逐仓杠杆 25×。仓位取计划净止损预算为权益的 1%、可用保证金和开仓费、买卖一档可见量及合约档位上限中的最小值，再按 `lotSz` 向下取整。计划止损跨过强平价格时不建仓。25× 决定保证金，并不把全账户每笔都挂到 25 倍。
- 使用相同的 `detect_setup`、`priced_candidate`、Skill 请求、二次验价和十五分钟信号冷却。从收盘约两秒后读取证据；候选经模型确认后，重新验证价差、漂移、资金费预算及复核期间退出触价。确认后的新报盘必须达到候选价或更优。按该买卖一档和可见量做模拟即时成交；不足一档时不假设能扫到后续报价。冷却从成功发布的信号计时，即使账户因已有仓位等原因没有开仓。
- 以真实成交触发止盈止损，按触发秒内第一笔越线的成交价加不利滑点（0.02%）并按 tick 向不利方向取整。单边手续费 0.05%，以成交名义价值计。已过结算时点的持仓按真实费率及结算前可见标记价计入逐仓资金费。按标记价和维护保证金检查强平，同一秒内标记价和成交价无法排序时优先处理强平并记下歧义。期末仍持有的仓位按最后可用标记价计入权益，不人为平仓。
- 回放使用共享 `PaperAccount` 和 `process_second` 处理状态顺序。从真实 L2 重建初始和复核报价，使用实际模型耗时加约一秒的刷新预算回到历史时间轴。实时读取新行情及响应的实际到达时间；二者的订单规则相同，网络和模型时序不是同一个历史记录。评估时会预先并行研判部分随后被冷却拦截的候选；资金账本只接受按时序通过冷却的信号。

## 行情与假设

- 来自 OKX 的已收盘一分钟成交 K 线，月档和 REST 在衔接处重叠对账；十五分钟和一小时由同一组成交 K 线聚合。盘中用实际一秒成交、标记价、触发秒逐笔成交，以及 L2 买卖一档。行情 API 文档见 [OKX V5](https://www.okx.com/docs-v5/en/) 和 [历史市场数据](https://www.okx.com/historical-data)。
- 缺少当时的实时预估资金费快照，两种模拟都以已知上一期实际费率作为下一期的估计。已有仓位的结算使用当期的实际费率。避免把未来结算结果喂给当前候选。
- 账户费采用策略费率；合约面值、tick、张数和第一档维护保证金来自回放执行时的 OKX 公共规格。没有该用户的实际手续费档位及全段规格变更档案。买卖一档用于入场模拟；离场假设固定滑点，不模拟私有撮合时延、价格保护、订单队列或平台强平实际成交。如果 `trade_1s_unmatched` 非零，逐笔与秒线无法匹配，报告单独计数。
- 模型研判在回测运行日完成，使用当时可见的历史证据；模型与服务档位以实际响应为准。服务不保证重复生成完全相同的判断。权益曲线按分钟及成交事件采样，最大回撤不等于连续逐笔回撤。模型接口成本和账户交易成本分开披露。

## 输出

`summary.json` 汇总结果、信号漏斗、数据覆盖、模型用量和各策略盈亏。`trades.csv` 列出每笔已平交易与逐笔触发证据；`equity.csv` 是权益及可用余额，`entries.jsonl` 给出未开仓原因，`events.jsonl` 记录开仓、资金费和退出。CSV 中交易时点是 UTC Unix 毫秒；权益时点为带时区的日期时间。
