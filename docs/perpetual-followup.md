# 永续持仓子 agent

每条新开仓信号按现有模拟入场时点创建一个持仓子 agent。ID 与信号一一对应，服务重启后沿用原 ID。已有信号继续补算历史结果。停止开仓监控后，已创建的子 agent 继续处理各自的持仓。

子 agent 用完整的已收盘一分钟 K 线记录持仓后的走势。若价格最大有利变动达到初始止损距离，随后从峰值回吐至少半个止损距离，且当前盘口在计入手续费和滑点后仍盈利，可以建议提前止盈。若连续两根收盘价跌破多单的结构支撑或升破空单的结构阻力，且当前不利变动超过半个初始止损距离，可以建议提前止损。触发后交给模型解释并复核，发消息前再检查盘口和止盈止损是否已被触及。提前建议每类每单只发一次，原信号继续追踪。

模拟结案按第一个有序成交触发的止盈、止损或持仓到期计算。止盈标记成功，止损标记失败。到期退出按含双边手续费和出场滑点的模拟收益方向标记，资金费未计。每条微信通知固定三行，依次为子 agent ID、成功或失败、含合约和触发原因的正文。提前提醒的状态对应建议发出时的模拟盈亏，正文标明仍在追踪。

通知使用原微信绑定。结案消息持久保存至送达。提前提醒过期或同一单已有结案时跳过。验收用两个独立交易的行情样本验证分配、准备退出、结案和重启去重，再验证网络恢复后的推送。
